CodHQ BOIII

This is the update site for the CodHQ BOIII client. It is not a web page you play on: the client reads the files below.

Download

  • codhq-boiii.zip: the client executable and its whole data tree.
  • boiii.json: the published file list with size and SHA-1 of every entry.
  • boiii/boiii.exe: the client executable on its own.
  • versions.json: the releases the launcher's version selector offers.

Installing

Install it from the CodHQ setup utility, which pins this release by the SHA-256 of codhq-boiii.zip and checks every file against boiii.json before and after writing. An installed client updates itself from this site when it starts.

Source: LarkTheStar/codhq-boiii.
